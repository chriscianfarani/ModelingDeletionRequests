# Adaptivity Gap

Code for determining lower bound on adaptivity gap in a three-subpopulation setting.

utilities.py: Contains functions to compute the optimal utility of nonadaptive and thresholded adaptive requesters (in the parameter regime defined in the proof of Theorem 2 in Section VI.B), as well as the adaptivity gap.

optimize\_util.ipynb: Notebook for performing grid search to maximize adaptivity gap (as described in section VI.B) and visualizing results.
