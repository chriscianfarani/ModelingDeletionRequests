# ModelingDeletionRequests
Replication code for the paper "Modeling Deletion Requests in Machine Unlearning".

adaptivity\_gap/:
Contains code for running a grid search to maximize the adaptivity gap for individual requesters as described in Section VI.B.

experiments/:
Contains code to replicate the unlearning experiments on the CIFAR-10 dataset as described in Sections VII.C and VII.D.

All dependencies can be auto-installed using the [uv package manager](https://docs.astral.sh/uv/).
